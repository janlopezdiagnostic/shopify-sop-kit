# Examples: intentionally empty

There are no worked examples in version 0.1, on purpose.

An invented example would teach the writer to sound right instead of be
right, which is the failure this kit exists to prevent. Examples get added
only when all of these are true:

1. The example came from a real SOP the operator wrote with this kit.
2. The operator followed the follow-it-cold checklist and the fixes are in.
3. Every store, brand, person, SKU, and price identifier has been scrubbed
   and replaced with plainly invented data.
4. The operator has approved the final wording.

Until then, this folder stays empty, and that emptiness is the honest state
of the kit.
