# Privacy and genericization rules

This kit was built from a real operator's real work. None of it is in here.

Never committed to this repo, in files, examples, commit messages, or issues:

- The store or brand name, in any form, including abbreviations.
- Any person's name.
- Store URLs, location names or addresses, account details, supplier names.
- Real SKUs, real order numbers, real prices from the operator's store.
- Screenshots or exports from the operator's Shopify admin.

Allowed: generic role names (store manager, ecommerce lead, associate),
generic retail language, Shopify's own public terminology, and invented
example data clearly marked as invented.

Sample data rule: if an example needs a product, it is a plainly generic one
("Example Product, size M, invented SKU EX-1001"), never a lightly disguised
real one.

Before anything from this repo is shared publicly, run a scrub pass: search
the full text for names and identifiers from the source material, and have
the operator approve the final wording of anything derived from their drafts.
